# Security Policy

## Supported Versions

We actively support the following versions of CyberShield NGO with security
updates. Older releases are no longer maintained and may contain unpatched
vulnerabilities.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of CyberShield NGO seriously. If you discover a security
vulnerability, please report it responsibly so we can address it before it is
publicly disclosed.

### Responsible Disclosure

1. **Do not open a public issue.** Please keep vulnerability details private
   until a fix has been released.
2. **Email us** at `security@cybershield.example.org` with the following:
   - A description of the vulnerability and its impact.
   - Steps to reproduce (proof of concept if possible).
   - The affected version(s) and environment.
   - Any suggested remediation.
3. **Acknowledgement.** We will acknowledge receipt of your report within
   **72 hours**.
4. **Investigation & fixes.** We aim to triage and provide a remediation
   timeline within **7 days**. Critical issues are prioritized.
5. **Coordinated disclosure.** Once a fix is available, we will coordinate a
   public disclosure date with you, typically within **90 days** of the
   initial report.
6. **Recognition.** With your permission, we are happy to credit you in our
   release notes and security advisories.

### What to Expect

- You will receive regular updates on the status of your report.
- If the issue is accepted, we will work with you on a coordinated release.
- If the issue is declined (e.g. not a real vulnerability or out of scope),
  we will explain our reasoning.

### Out of Scope

The following are generally considered out of scope for our security program:

- Social engineering of our staff or volunteers.
- Denial-of-service testing against live infrastructure.
- Issues in third-party dependencies that are already tracked upstream.

### Signature Verification

When relevant, security advisories and releases may be signed. Verify
signatures against the published maintainer keys before trusting downloaded
artifacts.

Thank you for helping keep CyberShield NGO and its community safe.
